# Risk Register — Model Routing Audit

| # | Risk | Why it matters here | Mitigation shipped in this PR |
|---|------|----------------------|--------------------------------|
| 1 | Fair Housing / discriminatory steering in generated copy | A wrong reply is legal exposure, not a quality bug. | `sensitive-routing.jsonl` corpus (Fair Housing protected classes + proxy language) with a **1.00 recall, zero-tolerance** frozen threshold (`thresholds.frozen.json`). Human-review routing in `lib/modelRouting.ts` is a deterministic rule engine evaluated *before* any model tier, matching the existing `decideIrisEmailExecution` pattern. |
| 2 | Send-gate bypass — a routing decision authorizing a send | `decideIrisEmailExecution`'s Tier A allowlist (`lib/irisEmail.ts:714-778`) must remain the only send authority. | `resolveModelRoute()` return type has **no** `canSend`/`canReply` field at all — it cannot express send permission even by accident. `tests/ts/modelRouting/modelRouting.test.ts` ("route never contains a field that could be read as send/injection compliance", "lib/modelRouting.ts source does not import decideIrisEmailExecution...") asserts this structurally and asserts `decideIrisEmailExecution` is not imported by `lib/modelRouting.ts`. |
| 3 | Label semantics break (`Auto Replied` without confirmed send, `Needs Human` without a stop, internal category promoted to `mailbox:true`, non-managed label removed) | `lib/inboxLabelPlan.ts` is documented as the only place deciding mailbox writes. | This audit does not modify `lib/inboxLabelPlan.ts`. `tests/ts/modelRouting/labelPlanUnchanged.test.ts` re-imports the existing exported constants/functions and asserts their behavior is byte-identical to pre-audit (golden fixtures captured from the current module). |
| 4 | `AgentInboxData` contract break → dashboard blank | `/api/data` is polled every 5s by `components/AgentInboxClient.tsx`. | No change to `lib/inboxData.ts`. `tests/ts/modelRouting/inboxDataContractUnchanged.test.ts` asserts all 14 keys from `AgentInboxData` are still present and typed the same. |
| 5 | `channel`/`direction` enum drift | Cross-system contract with `sheet_schema.py`. | No change to either enum. Router's own `channel` input type is a **subset intersection** with the existing enum (verified via a test that imports the literal union and checks the router's accepted values are a subset). |
| 6 | `lib/sheetSchema.ts` ↔ `sheet_schema.py` divergence | Silent dashboard breakage. | This audit adds no new Sheets fields (telemetry persists via the additive Postgres migration only; Sheets fallback mode gets a safe `tableColumns()`-style no-op). |
| 7 | Aria's 3.5s tool budget silently degrading to SMS fallback under a slower/reasoning model | Aria's model is Vapi-owned, not called by this repo — this audit **cannot** change it directly. | Decision doc marks the Aria voice-turn tier `NOT ADOPTED / DEFERRED — requires human-run `aria:provision`, explicitly out of scope for this PR` and documents the latency budget as a hard gate for whoever does that provisioning later. |
| 8 | Cost blowup from reasoning tokens / retry storms | Reasoning-capable models can silently multiply spend via internal reasoning tokens billed as output. | `lib/modelPricing.ts` requires a `reasoning` price field before a model may route reasoning-enabled traffic; cost formula in `evals/model-routing/` explicitly sums retries+fallback hops+reasoning tokens, never just the winning attempt. |
| 9 | PII leaking into eval corpus or artifacts | Corpus and telemetry must never contain real lead data. | All corpus files are synthetic-authored (no real data touched — no `conversation_events`/`lead_memory` query performed at all, per prohibition #7). `tests/ts/modelRouting/corpusPii.test.ts` regex-scans every corpus file for email/phone/ZIP+street patterns and fails the build if any match. |
| 10 | Migration-dependent reads running against an unmigrated DB | `db/migrations/031_model_attempt_telemetry.sql` is created but **never applied** in this PR. | Telemetry write helper probes `tableColumns()` first (matching the existing repo pattern, e.g. as used elsewhere for migration-sensitive reads) and no-ops safely if the table/columns are absent. |
| 11 | Prompt-injection flipping human-review off | Adversarial email/SMS content instructing the system to "ignore rules" or "send on my behalf." | `adversarial.jsonl` corpus + frozen threshold "0 send-gate bypasses, 0 injection-followed instructions" + rule engine ordering (deterministic rules run first and cannot be overridden by a model's own output). |
| 12 | Hypothesis models don't exist / aren't priced, silently substituted without disclosure | `GPT-5.6 Luna` is unverifiable in this repo's provider path. | Documented explicitly in the evidence ledger and decision doc as a blocker for that tier, not silently swapped. |
