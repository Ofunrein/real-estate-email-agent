# Corpus Provenance & Sanitization

All files in this directory are **100% synthetic**, generated by
`scripts/generate-model-routing-corpus.mjs` (deterministic, no `Date.now()`/`Math.random()`, re-runnable).

- **No real message, lead, or transaction data was read to build this corpus.** Per audit prohibition
  #7, `conversation_events`, `lead_memory`, and mailbox content were never queried — not even for
  aggregate shape. Fields/enums (`intent`, `compliance_flags`, `budget`, `timeline`, `area`, `beds`) were
  authored from the repo's own classification schema in `lib/irisEmail.ts` and this audit's own risk
  register — not from observed customer text.
- Neighborhood names (`Zilker`, `Mueller`, `Hyde Park`, `Del Valle`, `Cedar Park`, `Round Rock`,
  `Georgetown`, `Kyle`) are real Austin-area place names used only as generic area labels, never paired
  with a real street address, real price, or real person.
- No real names, phone numbers, emails, MLS IDs, or street addresses appear anywhere in the corpus.
  Street strings in `voice-turn.jsonl` (e.g. "1203 Main Rd") are fabricated test fixtures, not real
  addresses.
- `tests/ts/modelRouting/corpusPii.test.ts` fails the build if any corpus file matches: an email regex,
  a US phone regex, a `+1` prefix, an `@gmail`/other mail-provider handle, or a 5-digit ZIP adjacent to a
  street-suffix word. This test must stay green.
